# RecipeHub — фронтенд сервиса обмена рецептами

Учебный проект по дисциплине «Фронтенд-разработка» (ИТМО).
Вариант №5: сервис для обмена рецептами и кулинарных блогов.

## Текущий этап — Лабораторная работа 1

Вёрстка сайта средствами HTML, CSS и Bootstrap 5. Функциональность, для
которой действительно нужен JavaScript (модальные окна, валидация форм,
фильтрация, лайки/подписки/комментарии), реализована на нативном JS.
Данные — заглушки, состояние хранится в `localStorage`.

## Стек

- HTML5 (семантическая разметка)
- CSS3 (CSS-переменные + минимальный слой поверх Bootstrap)
- Bootstrap 5.3.8 (подключён локально, файлы лежат в `assets/vendor/bootstrap/`)
- JavaScript (ES-модули, без сборщиков и зависимостей)

## Запуск

Проект использует ES-модули, поэтому открывать страницы нужно через
локальный веб-сервер (просто двойной клик по HTML-файлу не подойдёт —
браузер заблокирует импорт модулей).

```bash
# из корня проекта
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

Альтернатива, если установлен Node.js:

```bash
npx serve .
```

## Принятые условности

- Пути к ресурсам строятся относительно корня проекта, который задаётся
  атрибутом `data-root` у `<body>` (`""` для `index.html`, `".."` для страниц
  в `pages/`). Так страницы работают и локально, и на GitHub Pages.
- «Фотографии» рецептов — локальные SVG-заглушки, чтобы не зависеть от
  внешних сервисов.
